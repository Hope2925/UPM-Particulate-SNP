# Differential Expression ANalyses
## Brief Description
This folder includes Differential Expression, GO, and comparing such results between WSP and UPM. 
## Files
* **Diff_Exp_UPM.ipynb** and **Diff_Exp_WSP.ipynb** contain the same code but for UPM and WSP data, respectively. It includes differnetial expression analysis of genes and NonTSS bidirectionals, both of which are then used to make ranked files for TFEA. GO analysis on the early, early plateau, and late response genes is also performed.

* **Compare_Gene_tREs_GO_WSPp001.ipynb** is where I compare the early, early plateau, and late response GO terms, genes, and tREs between WSP (padjusted cutoff of 0.001) and UPM (padjusted cutoff of 0.05).
